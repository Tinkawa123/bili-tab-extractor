# 观众试片反馈 · judgeD

> 身份：28 岁，弹吉他 2 年，B 站/YouTube 重度用户。看的是 `out/preview_v1.mp4`（960×540 / 60s / 有声音），逐帧看过 1800 张截图 + 全程音量波形 + 画面运动量。以下按"第一遍坐在电脑前看"的真实反应写，不客气。

---

## 一句话总评

**产品是真能用的，中间"谱子一行行堆起来"那段确实有点东西；但整片只有 540 线、小字全糊，后半段 20 秒像 PPT 定格，最后一句台词还写错了一个字——初剪能看，现在这样就发出去会被当成"AI 糊出来的花架子"。**

---

## 7 条「最想吐槽的点」

**1. 47.9–58.9 秒：11 秒半几乎一动不动，结尾还不告诉我"去哪拿"**
两句 slogan 静静放在那儿 4.5 秒，然后 logo 卡又静放 5 秒（我数了逐帧差，这 11 秒画面运动量只有 0.2–0.6，就是"没在动"）。60 秒的片子，最后 1/5 是静止的。更致命的是：全片没有一个链接、一个二维码、一个"搜什么"、一句"免费/多少钱"。我看完想用，但**完全没门路**，这等于白做。结尾只有一行没人能读的 "BILIBILI → PDF · LOCAL · 300 DPI" 在装样子。

**2. 55.35 秒：错别字，"一键扒谱 · 专治手截"**
"手截"……是"手残"吧？全场最后一句、最像口号的、最该被截图转发的那一句，挂了个错字。这不是风格问题，这是校对没做。一秒钟让全片掉一个档次。

**3. 53.5 秒：产品名的出现方式像渲染出错**
"视频扒谱工具"是用横向擦除揭出来的，那 0.9 秒里字被从中间切掉一半（横画只剩上半截），看着像重影 / 卡帧 / 码流坏了。我第一反应是"这视频文件是不是坏了"，而不是"哦这是设计"。

**4. 08.0–13.0 秒：整个 App 窗口"冻"在那儿 5 秒，里面的字我一个都读不到**
这 5 秒画面运动量 0.2–0.5，基本就是一张静止截图（只有打字光标和进度条在动）。而这张截图里装着全片最重要的信息——"抽帧间隔 2.0s / 分辨率 原始 / 核验 开启"、"下载视频 → 抽取帧 → 检测谱行 → 去重排序 → 输出 PDF"。这些字在 540p 下只有 7–8 像素高，等于没有。**产品长什么样、能调什么，我第一眼全错过了。**

**5. 34.0–35.5 秒：界面被放到出画，按钮直接切掉**
为了强调"确认输出"，镜头把核验窗口推得太近，右边被裁掉（"确认输出 PDF"整颗按钮少一半），35.5 秒连顶栏和标题都出画了。这不像设计，像手滑。一个挑剔的观众会想："连展示都裁不齐，工具靠谱吗？"

**6. 37.0–44.0 秒：同一张 A4 纸换了四个机位，转了 7 秒**
而且 41.5 秒那一整帧是虚的（焦外 + 泛光糊在一起），纸上的谱子看着像雾里。左下角"04 / 成品"和"A4 PDF · 直接打印。"是暗灰字贴暗棕底，等于没写。7 秒啊，够我把朋友圈刷两屏了。

**7. 16.0–25.0 秒：三个裸数字，386 / +48 / −12，我不知道它们是什么**
"帧 / 行 / 重复"这些单位字是 13 像素、50% 透明的灰，贴在青绿底上，完全看不见。所以我眼里就是三个大数字在跳，其中 `−12` 还是负号琥珀色——**像"扣分""亏了 12"**，不像"帮你删了 12 行重复"。同理 25.0 秒左下角突然冒出一个孤零零的青绿 `3 A4`，出现不到 1 秒就没了，我都没来得及看。

## 3 条「最想夸的点」

**1. 15.0–22.0 秒：谱子从视频里被一行行抽出来、在右侧码成一列。**
这是全片唯一一个"不用解释就懂了"的镜头。左边是真人弹琴 + 下方谱面在滚，右边一行一行白条往上叠，配合数字跳。**我看完这 7 秒就明白这工具干嘛的了**——这比任何旁白都强，是这支片子真正的价值所在。

**2. 23.5–25.0 秒：一列碎行"收拢"成一张 A4 页。**
从"一堆条条"变成"一张完整的谱"，这个从碎到整的动作有明确的"成了"的快感。这是第二好的镜头，节奏也刚好。

**3. 46.0 秒：贴脸给你看 PDF 里真的有和弦、有六线谱、有歌词。**
这 1 秒是唯一的"证据镜头"——不是渲染的概念图，是能打印的东西。对弹吉他的人来说，看到"雪花饮泣的你冻吗 / 这风楼我"这种歌词配六线谱，可信度瞬间拉满。**可惜只给了 1 秒。**（顺带说：46 秒那页其实暴露了输出观感——每行谱都是灰底截图条贴在白纸上，像复印拼贴，不太像"排好版的谱"。）

# 逐题回答

## 1）0–10 秒：会继续看，还是会划走？

**会继续看，但理由不是"这视频做得好"，是"这是真吉他手、真谱面"。**

- 0.0–6.0 秒：吉他琴颈特写 + 底部一整条谱面在横向滚 + 大字"谱面在滚。／截图在追。"（琥珀色那句 2.92 秒才出来）。这个开头对弹琴的人是有效的——我一秒就知道"哦这是扒谱的事"。**但**：底部那条谱面占了画面下方 1/3，是一条发灰的白带，把画面压得很沉；而且前 0.9 秒一个字都没有，纯暗画面，在 B 站的信息流里这 0.9 秒要赌一把。
- 6.0–7.5 秒：一群截图"散开"飞出来——**这里我第一次皱眉**，因为卡片边缘有一圈发白的边/光，像劣质抠图，像 PPT 的"形状动画"。
- 7.5–10 秒：App 窗口弹出来，配上"粘贴链接，点一下"。**这里我第二次差点划走**：窗口里所有字都读不到（只有 7–8 像素），而且窗口在接下来 5 秒几乎不动，感觉像"看看我的软件截图吧"。

**结论：撑过 10 秒的主要动力是"我想知道它到底怎么把谱拼起来"，不是画面本身。**

## 2）哪些瞬间让我觉得「哇，有点东西」？（带秒）

- **15.0–22.0 秒**（最强）：单行谱从视频里被一行行抽出来，在右边码成一列，数字 386 → +48 一路跳。
- **23.5–25.0 秒**：一列碎行收拢成一张 A4 纸。
- **46.0 秒**：贴脸展示 PDF 里真的六线谱 + 和弦 + 歌词（可惜只 1 秒）。
- **37.0–40.0 秒**（半个）：纸挂在墙上、光打过来那一下，质感是不错的——只是这个画面我看过一百遍了，属于"好看但眼熟"，不算"有点东西"。

## 3）哪些瞬间让我觉得「廉价 / 尴尬 / 看不懂 / 像模板」？（带秒）

- **6.0 秒**：截图扇形散开，卡片白边发光，PPT 形状动画既视感。
- **13.9–15.0 秒**：一条青绿光带横扫换场，然后**之后 30 秒全是这个青绿底**。这股"青绿渐变 + 发光"就是典型的 AI 生成宣传片配色，我一眼就警觉了。后面每次切回青绿底（16、19、22、25 秒）都在强化这个印象。
- **26.2–26.4 秒**：白闪一下换场。廉价。
- **26.5 秒**：核验窗口从灰底里浮出来，前两三秒全是"灰字贴灰底"，像没调好对比度。
- **31.0 / 32.5 秒**：行在拖，但文字说明"重复的，删掉。"（29.9–32.3 秒）在动作**还没做完的时候**就撤了，因果反了，看得我一愣。
- **34.0–35.5 秒**：界面推出画，按钮被切（见吐槽第 5 条）。
- **41.5 秒**：整帧虚焦 + 泛光，糊成一片棕雾。
- **53.5 秒**：名字被横向切开一半，像渲染 bug。
- **55.35–58.9 秒**："一键扒谱 · 专治手截"——错别字。
- **59.5 秒**：直接黑掉，没有最后一下停顿。

## 4）文字有没有看不清 / 看不懂 / 太挤 / 太小？（带秒）

**太小、看不清（最严重，全线问题）**：

- **8.0–13.0 秒**：App 里所有设置项/"抽帧间隔 2.0s / 分辨率 原始 / 核验 开启"以及底部"本地处理 · 不上传视频 · 可随时中断"——7–8 像素高，手机上必糊。
- **8.0–25.0 秒**：左上角章节标签"01 / 输入""02 / 抽取"——15 像素 + 60% 透明 + 灰字贴黑底，**等于没写**，我第二遍逐帧才看见。
- **16.0–25.0 秒**：左下角单位标签"FRAMES / 帧""TAB ROWS / 行""DUPLICATES / 重复"——13 像素半透明，看不见（见吐槽第 7 条）。
- **6.0 秒**：右上角"已截图 37 / 可用 00"——标签看不清，只见 37 和一个**红色的 00**，红色数字像报错。
- **26.5–35.5 秒**：核验窗口是 1280×720 的界面塞进 960 宽还继续缩，一行缩略图上叠了"01 / 第 1 行 / 1917×166 / t=0s / 正常"五层信息——**又小又挤**。
- **34.0–35.5 秒**："确认输出 PDF"按钮里的字被裁掉一半。
- **41.5 秒**：左下"A4 PDF · 直接打印。"暗灰贴暗棕，基本消失。
- **53.5 秒**：产品名被切一半。
- **56.0–59.0 秒**：结尾副标题"B站教学视频 → 完整吉他谱 / A4 PDF"约 9 像素；最下面那行 "BILIBILI → PDF · LOCAL · 300 DPI" 纯装饰，谁都读不到。

**看不懂 / 有歧义**：

- **22.0 秒**：`−12` 用负号 + 琥珀色，像"扣了 12 分"，其实是"删掉 12 行重复"。
- **25.0 秒**：孤零零一个 `3 A4`，不到 1 秒，谁也不知道是"3 页"。
- **数字对不上**：先给 `+48` 行，再 `−12` 重复，后面窗口写"25 行谱面 · 4 组疑似重复"，导航又写"48 块"。48−12 该是 36，怎么变成 25 了？**较真的人（比如我）会出戏，觉得数据是编的。**
- **54.0 秒以后**：没有任何"在哪下"的信息。

## 5）画面有没有糊 / 噪点脏 / 颜色脏 / 黑得没细节 / 白得刺眼？（带秒）

- **全片分辨率只有 960×540，码率 706 kb/s**——这是"糊"的根源。你在 1920×1080 里设计的 13 像素小字，导出成 540 后只剩 6–7 像素，所以整片的小字全灭。
- **16.0 秒 / 22.0 秒**：青绿渐变底上能看到**一块一块的方块**（8bit + 低码率在平坦渐变上的色带），近看像脏印子。
- **2.0 秒 / 6.0 秒**：底部那条谱面是"发灰的白"，不通透，像截图没清理干净就贴上去。
- **0.0–4.0 秒**：右上和右侧大半是死黑，琴身细节没了（当然这片子走的是暗调，可以接受，但**加上底部的白带就是"上半死黑、下半发白"**，画面被劈成两半）。
- **26.5 秒**：灰字灰底，对比度不够。
- **34.0–35.5 秒 / 32.5 秒**：白底界面铺满屏幕，是刺眼的那种白（偏冷、无层次），紧接着又切回全黑，眼睛被反复闪。
- **41.5 秒**：整帧虚焦 + 泛光 + 棕雾，是"最脏"的一帧。
- **43.0 秒**：纸的顶边有点过曝，白成一片没纸纹。
- **颜色**：整体调色是统一的高级感（米白 + 墨黑 + 青绿 + 琥珀），**但青绿太饱和、太"数码"**，在 13.9 秒那条光带出现时，我基本确定"这是 AI 风宣传片模板"。

## 6）哪一段想快进？哪一段太短没看清？

**想快进：**

1. **37–44 秒**：七秒，同一张纸。我在 40 秒就想拖进度条了。
2. **47.9–58.9 秒**：十一秒半几乎静止，最想快进的就是这里——而且快进完发现后面没了。
3. **08–13 秒**：五秒的静止软件截图，只想跳过。

**太短 / 没看清：**

1. **24.1 秒的"3 页 A4"**：0.7 秒就被下一页转场吃掉，这是最关键的结论数字之一，一闪而过。
2. **46.0 秒的 PDF 特写**：只有 1 秒，全片最好的证据镜头，给太少了。
3. **12.25–13.55 秒"剩下的，交给它。"**：两行小字挤在左下，1.3 秒就没了，紧接着青绿光带扫过来。这句其实是全片的"承诺"，被当成过场处理。
4. **32.7–34.7 秒"确认输出。"**：刚说完就推近裁掉按钮。
5. **"37 张截图，拼不成一首歌"**（6.0 秒附近那行小字）：这句是全片唯一提"痛点"的，但只是一行小灰字贴在那里，念都来不及。**痛点是"说"出来的，从来没"演"出来**——没有人真的一边暂停一边截图、贴到 Word 里对不齐的狼狈画面。这是全片最大的内容缺口，比任何一个技术瑕疵都致命。

## 7）看完你记住这个产品叫什么、干什么用的吗？你会去搜吗？

- **干什么用的**：记得非常清楚。**"把 B 站吉他教学视频里的谱面自动截下来，拼成完整谱，导成 A4 PDF。"** 这点我给它满分，15–25 秒那段把这事讲透了。
- **叫什么**：记得是"视频扒谱工具"。**但这更像是"功能名"，不是"品牌名"**——满 B 站搜这四个字，出来的大概率是各种教程和别的软件。我记不住它、也没法把它传播出去。
- **会不会去搜**：**大概 40% 会去搜**。因为我想用，但片子没给我任何入口。如果真去，我会搜"B站 吉他谱 自动截图 工具"这种词，靠运气撞见。这等于把已经到手的意向用户丢在路上。
- **会不会转发**：**不会**（52 分的直接原因）。转给琴友，他也会问"哪下"，我答不上来。
