## 2. 最伤的 7 个具体问题

### ① 【0.90–5.95s 全程｜主线 y=560】主角线横穿第二行标题「截图在追。」= 删除线
`scene1()` 里主线画在 `y=560`（`over(img, solid(lw,2,D.TEAL), (W-lw)/2, 560, 0.65*seam, "add")`）。
实测第二行「截图在追。」的墨迹范围是 **y 512–599**，x 154–573。线正好切在 55% 高度，穿过"图/在/追"三个字——读起来就是一道**删除线**。这是全片第 1 秒就在毁标题的错误。preview 里它被 0.65 压暗所以偏灰，当前 build 提亮后更刺眼。
**怎么改**：把 seamer 下移到 `y=660`（第二行墨迹底 +61px），并让它**绕开字块**：画两段 `x 640→1720`（字块右缘 573 之外）与 `x 0→90`，中间用一个 `GaussianBlur(sigma=18)` 的 alpha 缺口过渡；或整条线降到 `y=690`（正好落在 S1 左栏底部与谱面带之间，成为"分隔线"而不是"删除线"）。透明度 0.65 → 0.45，线宽 2 → 3px（更"发光"而非"细切"）。

### ② 【4.30 / 4.95 / 5.60s 三次全屏白闪 + 7.00–7.20s 白场硬切】
`scene1()` 的截图闪光用 `img = img*(1-fl*0.55) + fl*0.55` —— **整帧**混 55% 白，连标题和右上角统计一起洗掉。实测 t=4.40 全片平均亮度从 44 飙到 **112**、p99=250，标题被冲成牛奶灰几乎读不出来。紧接着 `_flash_cut(7.0,7.2)` 用 `fl*0.95` 打了 **6 帧近纯白**（占 0.2s）。
7 秒里 4 次全屏闪白 = 评委眼里的"用力过猛 + 廉价转场"。
**怎么改**：
- 三次闪光只作用于取景框内 `x 1492–1790, y 130–420`：`fl_in = fl`、`fl_global = fl*0.18`；取景框内再加一个 0.35 白底 + reticle 四角 `op=fl` 的爆闪。
- 背景 glitch 切片保留，但幅度 24px → 10px，只作用在 `y 620–900`。
- 7.0–7.2 的白场换成 **0.13s 的"曝光过载"**：`fl*0.45` 叠一层青绿 `#16E3AE @0.12`，或直接借用音频重拍做 3 帧硬切（不要白场）。

### ③ 【0–7.2s｜谱面纸带 y≈745–1030】全片最亮的东西是一块薄荷灰的板，而且直边
实测这条纸带的纸色 = **(200, 226, 225)** —— 青绿偏冷的薄荷灰，R 比 G/B 低 26。原因在 `_video_world()` 的 `tab *= np.array([0.80,0.85,0.86])` 加上青绿 `glow_field` 叠加。它同时是画面最亮区（均值 142/255，占画高 26%），顶部是**一条完全笔直、无阴影、无透视的硬边**（y=745，跳变从 0.4 → 114）。于是观众第一眼的"纸"是**一块薄荷色塑料板**，品牌纸 `#F4EFE5` 一次都没出现。
**怎么改**（三行以内）：
1. 校色：`tab = tab*[1.035, 0.995, 0.930]` 后再 `tab[...,2] *= 0.94`，把 (200,226,225) 拉回 ≈ (208,224,209)；再把那块 `glow_field` 的 gain 0.22 → 0.09、位置从 `(0.76W, 0.04H)` 移到纸带**上方 120px**（让光打在纸的上沿，不是压满整块纸）。
2. 边：在 `y 700–745` 加 45px 高的 0→0.55 黑 scrim；纸带顶沿加 `solid(W, 2, "#000") @0.35`。
3. 透视：`warpPerspective` 让纸带下沿比上沿宽 2%（`src [(0,745),(W,745),(W,1030),(0,1030)] → dst [(0,745),(W,745),(W+18,1030),(-18,1030)]`），再在顶部 90px 叠 0.10 的白玻璃反光（左高右低）。

### ④ 【36.2–45.6s｜整张 A4】纸不是纸：先是中性灰，暖只在最后 1 秒出现，而且没有一张"正视全页"的主镜头
实测同一块纸的纸色：
- t=36.8 **（195,194,191）**，R−B=+4 → 中性灰白，无暖度；
- t=39.8 略升；
- t=44.0 **（244,243,235）**，R−B=+9 → 这才接近品牌纸 `#F4EFE5`（R−B=+15）。

也就是说，**观众等了 43 秒才第一次看到"纸"的颜色**。更严重的是纸内的谱行条带**比纸更黑**（still 实测条带 (78,77,72) vs 页 (104,102,96)）——变成"灰纸上的灰方块"，不是"纸上压墨"。整段 S5 也没有一张"整页 A4、正视、清晰、明亮"的主镜头：全部是 24–28% 画幅宽的斜放页（4° 倾斜），或者失焦微距。
**怎么改**：
1. 把纸做成物理量：`paper = #F4EFE5` 为基色，**只让光变化**：`light = 0.62 + 0.38*ease(t_in)`，最终 clamp 到 `lum ≤ 0.90`（永不削顶），并在纸上乘 `1 ± 0.025` 的蓝噪纤维（`grain(paper, t, 0.018)` 单独作用在页内，而不是全帧）。
2. 删掉每行条带的自带底色（现在每行是一块比纸更深的长方形），只保留墨迹 + 1px `#D8D0C2` 行分隔线。这一改动会让"纸感"当场成立。
3. S5 加一颗主镜头：**t 43.4–44.9（1.5s）** 整页正视、满画幅 70%、`rot=0°`、纸亮度 0.90、四角留 8% 安全边。这一帧是全片缺的"钱镜头"。

### ⑤ 【14.4–26.4s 与 26.4–36s】所有阴影和发光都没有衰减——一堆硬边矩形
- t=15.9 中央有一块 **x 760–1290 / y 320–560 的青绿矩形**，上沿和右沿是 0 像素过渡的硬边；下方还有一片 6 个更暗的同款矩形（x 760–1290 / y 440–700）。它们看起来像**没合成干净的 alpha 层**，不像设计。
- t=17.4 叠垛中间有一条被拉成白糊的重影条（运动模糊 sigma 过大 + 与下层叠加），像脏镜头。
- S2/S4 的 UI 窗口：投影是**硬边黑带**——窗口下沿（y=800）外有约 34px 深黑横带，左右在 x=470 / x=1750 处有可见的竖直硬边。窗口因此像"贴"在黑纸上，而不是立在房间里。
**怎么改**：
1. 幽灵矩形：要么删（它们不承载信息），要么 `mask → GaussianBlur(sigma=18) → alpha 0.06`；青绿块 gain 1.0 → 0.35，并把边缘 `sigma 24` 羽化。
2. 重影条：`GaussianBlur sigma 从 5.0+7.0*clamp(...)` 降到 3.0 封顶，叠加强度 1.0 → 0.5。
3. 窗口投影改两层：`shadow(spr, blur=96, opacity=0.55, dy=+44)` + `shadow(spr, blur=26, opacity=0.30, dy=+10)`，删掉现在这层 `dy≈18 / blur≈14` 的中间层（硬边就是它）。

### ⑥ 【45.6–60s｜片尾】品牌被拍得比副标题还小，还偏了 37px
实测 t=55.0 的锁形：mark **220×184px**（x 850–1069, y 291–474），品牌名 **397×46px**（字号约 66px，y 570–615），副标题 **471×20px**（字号 20px），整组只占画幅宽 **24%**（x 725–1195）。
对照：S6 的标题 couplet 是 **100px**（t=51.0 实测字高 71px、字距 94px/字）。**一张 60 秒片子的最后一个画面里，广告语比品牌名大 1.5 倍** —— 这是层级倒置。
细节问题：
- mark 高 184 = 品牌名的 3.2 倍，锁形头重脚轻；mark 与名之间空隙 96px（很散）。
- 页脚（`WINDOWS 桌面·免费下载`）**最亮像素 52/255，对比约 2:1** —— 等于不存在，纯噪点。
- 副标题 `#7C8A8D`，20px，对比 3.9:1 —— 低于 4.5，电视上看不清。
- couplet 两行是**左对齐**在 x≈620，墨迹块中心 923，而画布中心 960 → **整体偏左 37px**，且行 1/行 2 的字块中心差 22px（标点未悬挂、未做光学居中）。
**怎么改**：mark 220 → **360px 宽**（等比，mark 高 300）；品牌名 66 → **84px**；mark→名空隙 96 → 44px；副标题 20 → **22px**、色 `#8E9AA0`（对比 ≥4.5）；页脚**直接删**（或 18px `#6B777C` 放在 y=1000，但不进主视线）；couplet 用光学居中：把「，」「。」的字宽从行宽里扣掉再居中（`x = (W - ink_w)/2`，实测应为 x≈656 而非 620）。

### ⑦ 【全片 / 27.0s 最明显】辅助字系统整体失效 + 竖切 wipe 把汉字切碎
- `01 / 输入`、`03 / 核验`、`04 / 成品`（章节标）：实测最亮像素仅 **87/255**，字身约 `#373C3E`，约 18px 却配 3.0 宽字距 —— 在 960 预览里就是一道灰痕。它是全片唯一的"结构索引"，却看不见。
- `FRAMES 帧 / TAB ROWS 谱行`、行内元数据 `1917×166 · t=0s`（11–12px）—— 都是"能读但不想读"的灰噪点；在 960 预览里它们退化成线条，等于没有信息。
- 更严重的：`caption() → wipe()` 用**垂直渐变**做入场，把汉字沿上下方向切一半（t=27.0 的「勾一勾，拖一下。」被切成「勾1 勾1 一F?」）。全片 14 条字幕、每条 0.6s，等于 8.4 秒的"字是碎的"。
**怎么改**：
1. 章节标：18px → **26px**、色 `#8D999C`（对比 ≥4.5）、字距 3.0 → 1.6、位置固定在 `x=140, y=196`（并与右栏第 1 行文字基线对齐，现在差 15px）。
2. 行内元数据 11px → **18px** 或删；`FRAMES 帧` 这类标签 12px → 16px 且色 `#8E9AA0`。
3. `wipe()` 换成**逐行 mask 左→右扫描**：`a = clip((p*(1+feather) - X)/feather)`（X 是列坐标而不是行），feather 0.18 → 0.10；或最省事：改成 `dy` 位移 24px + 透明度 0→1 的 0.45s `ease_out_cubic`（不动字形）。汉字**不要**用纵向渐变切。

## 3. 3 个最该保留的亮点

1. **S1 的前 3 秒是真正的电影语汇**（t=1.2–3.3）：实拍吉他做底、整屏宋体双行标题压在暗部、纸带从下沿滚过、还有"截图碎片"从画面中央炸开又落成散页。这是全片唯一"有摄影机、有舞台、有物证"的段落，评委的第一印象就是它给的。别动它，只修 ③ 里的纸色和 ① 里的线。
2. **S3 的青绿暗房是全片最好的"房间"**（t=14.4–22.4）：中央一团青绿雾光、左侧小视频窗、右侧谱行垛、左下 386 / +48 / -12 的等宽数字板。这张图有"工作室监视器"的气质，而且数字板的字号层级（44px 值 / 12px 标签）是对的——它证明了这套视觉语言能撑住"工业感"。
3. **浅色纸感 UI + 深色工具条的反差处理**（t=28.5–32.0）：`已选 2 行·疑似重复｜保留第一个｜删除选中` 那条近黑工具条压在 `#F7F3EB` 面板上，是全片最"产品"的一笔，也是唯一一处真正像 Linear/Stripe 的地方。请把这种"深色条压在纸上"的语汇推广到 S2/S4 的其它控件。

## 4. 如果只能改 3 件事（从"不错"到"获奖"）

1. **让纸成为主角（一场戏 + 一个色）**：纸色在四场里锁死到 `#F4EFE5`（S1 那条薄荷灰带必须改暖，实测 (200,226,225) 是致命伤）；S5 加唯一一颗"整页正视、满画幅、无削顶"的主镜头（t 43.4–44.9），并删掉谱行条带的自带底色，让墨直接压在纤维上。**就这一帧，能把"工具演示"变成"作品"。**
2. **做减法：把所有"亮"和"边"降一半**。4 次全屏白闪 → 只在取景框内闪；青绿幽灵矩形 → 删或羽化；窗口硬边阴影 → 两层大模糊；S1 纸带硬直边 → 带阴影 + 2% 透视。全片目前"闪"的密度是获奖片的 3 倍，克制感是评委最先感知的东西。
3. **重做片尾 15 秒**：品牌名从 66px 放到 84px、mark 放到 360px 宽、删掉 2:1 对比的页脚、couplet 做光学居中（扣标点）；并且让主线**从谱行里被"抽"出来**，横穿画面后收成 logo 的那条横线——现在结尾是一个静止的贴纸，应该是一个动作的终点。
