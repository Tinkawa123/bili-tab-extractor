# judgeB 评审报告 ·「视频扒谱工具」60s 产品片初剪

**评审对象**：`out/preview_v1.mp4`（960×540 / 30fps / 含音轨）+ `out/frames_p1/f_00000–f_01799`（1800 帧，逐帧与 mp4 一致）
**音乐**：**我从 mp4 里抽出的音轨**（`out/jb/mp4_audio.wav`，60.01s，RMS −18.0 dB）。100 BPM，1 小节 2.4s = 72 帧；16 分 = 0.15s = **4.5 帧**（30fps 下 16 分音符天然落在半帧上，这是后面好几条问题的根）。
**方法**：15 组「相邻 6 帧」接触印相（1 帧步长看形变、3 帧步长看位移）+ 全片逐帧差分/亮度曲线/活跃像素比 + 音频 HF 瞬态与视觉事件互校 + 6 帧连续区段的缓动反演。
**两条必须说明的前提**：
1. `film/film.py` 的最后修改（21:09）晚于本片（21:03），工作区和这条初剪已经不同步；本报告只以**已交付的 frames_p1 + mp4 内嵌音轨**为准，代码仅作归因参考。
2. **`out/score.wav` 不是 mp4 里的那条轨**：score.wav RMS −15.5 dB / 快门音在 4.30-4.95-5.60 / 行 tick 步长 0.265s；mp4 音轨 RMS −18.0 dB / 快门音实测 4.295-4.900-5.495。也就是说**如果有人拿现在的 score.wav 重混到 frames_p1 上，音画会整体错位**——这是交付环节的隐患，先记一笔。

## 7 个最伤的动效 / 节奏问题

### 1【8.00–13.30】场景二 5.3 秒"活死人"：整段没有一次镜头运动

- **【秒】** 7.93–13.27（连续 5.34s）
- **【现象】** 逐帧活跃像素（变化 >10 灰阶的像素占比）在这 5.3s 里是 **0.0%–0.3%**，全段中位数 **0.07%**；唯一在动的是 1–2px 高的进度条、四行小字日志、以及左下角逐字打出的旁白。窗口本身在 7.22–8.05 入场后就**一动不动**，像一张被贴上去的截图——而且它只占画幅 71%×59%，四周是一整片死黑，视觉活跃度比 S1 掉了约 **100 倍**（S1 中位 7.38% ↔ S2 中位 0.07%）。
- **【修法】** ① 给窗口一条贯穿 7.2–13.6 的**单点透视推轨**：`ry` −14°→−9°、`scale` 1.03→1.00、`y` −18→0，`ease_in_out_sine`，**幅度 ≥8% 画幅高度**（现在的 0% 是致命伤）。② 进度条改成**分段跳格**：在 10.90 / 11.35 / 11.80 / 12.25 各跳 10–13%，每跳 `cubic-bezier(0.16,1,0.3,1)` **0.12s** 完成（直接跳，不要连续插值），并让数字用 `mono_bold` 滚字 3 帧。③ 四条日志改成 `y+14 → 0` + `opacity 0→1`，`ease_out_quint`(≈`cubic-bezier(0.22,1,0.36,1)`) **0.18s**，行尾加 1 个 0.1s 的 √ 打字机。④ 12.9 加一道**横向扫描光**（120px 宽青绿渐变，1.2s 从左到右掠过窗口），把"处理中"变成"被光读过一遍"。

### 2【7.20 / 26.40 / 36.00】三次硬切 = 同一个"闪白 5 帧 → 切到空画面 → 0.5–0.8s 淡入"模板

- **【秒】** 7.03–7.20、26.23–26.40、34.75–35.73（0.98s 白雾）、35.73–36.00
- **【现象】** 三次亮度曲线几乎一样：7.00 亮度 0.19 → 7.03 **一帧跳到 0.61** → 7.07–7.13 稳在 **0.82/0.83（帧间差 0.011，等于一张白卡被按住 5 帧）** → 7.20 切到 **0.08 近黑**；26.20 0.55 → 26.30–26.33 **0.88 两帧不动** → 26.40 切到 **0.08**。切完不是内容，而是**空**：7.20–7.30 是暗底上一个 50% 不透明的小窗口在飘，26.40 是第一帧纯空、26.47 才开始淡入，36.00 更狠——**36.00/36.03/36.07/36.10 四帧帧间差 0.000，完全一样的空橙底**，36.20 整页 100% 尺寸硬插进来。
  更糟的是 34.75–35.73：亮度恒定 **0.77**、帧间差 0.000–0.005，**连续 29 帧（0.97s）是一片过曝白雾**，里面只剩一点几乎看不见的 UI——这是全片信息量最低的一秒，却放在"核验→成品"的情绪最高点上。
- **【修法】** ① 闪白从 5 帧压到 **2 帧（0.067s）**，峰值放在切点**前 1 帧**（7.183 / 26.383 / 35.983），形如 `L(t)=1−|t−t_peak|/0.067`，不要用现在的 0.2s 正弦平台。② **切点后第 1 帧必须已有实体**：把窗口/卡片的目标态在切点前 1 帧就算完（`p=1`），入场改用 **0.28s**、`y +24→0`、`opacity 0.15→1`、`ease_out_quint`。③ 36.00 的第一帧就给出 page 的 `scale 0.86 / y+40 / opacity 0.55`，36.00–36.55 收到 1.0（`ease_out_quint`），让"落地"发生在 **36.55**——现在 36.00 有一记 −13.8 dB 的强 impact（比前一帧高 12 dB），但画面上是**四帧空橙底**，纸要到 36.20 才整页弹进来：**声音已经砸下去了，画面还空着 4 帧**，这一刀的分量全丢了。④ 34.75 的白雾整段删除，改为 **2 帧闪白 + 立即切到 S5**（把 0.97s 还给纸）。

### 3【4.30 / 4.95 / 5.60】三次快门：**画面比自己的音效越来越晚**，第三下晚了 4 帧

- **【秒】** 画面闪白首帧 **4.333 / 4.967 / 5.633**（间隔 0.634 / 0.666s）；音效 HF 瞬态峰值 **4.295 / 4.900 / 5.495**（间隔 0.605 / 0.595s，几乎正好 0.60s）
- **【现象】** 声音是等距的（0.60s，踩拍），画面却在 0.64–0.67s 上走——于是**画面逐次落后于自己的声音：0.038 → 0.067 → 0.138s（第三下整整 4 帧）**。这正是"越打越拖"的听感来源：第三下的白闪出现在快门声之后约 4 帧，像慢半拍的掌声。
  技术上还有第二个坑：**4.95 落在第 148.5 帧（半帧位置）**，30fps 必然渲染到 148 或 149（实测 4.967）。100BPM 的 16 分 = 4.5 帧、8 分 = 9 帧、拍 = 18 帧——只有 8 分及以上的格子能落在整数帧上；所有 16 分级事件都必须显式取偶数帧（4/5 帧交替），不能直接写小数秒。
- **【修法】** 三下画面改到 **4.30 / 4.90 / 5.50**（与音效同一时刻；对应帧 129 / 147 / 165，全是整数帧；相对拍点 4.2/4.8/5.4 统一 +0.10s，听感上"故意压后一点点"是一致的 swagger，而不是越走越散）。闪白时长 0.20s→**0.13s（4 帧）**。配套的卡片"落纸"改成：`scale 1.18→1.00` + `rotate ±6°→0`，**0.14s**，`cubic-bezier(0.34,1.56,0.64,1)`（overshoot 1.3），落点后 3 帧内 `scale 1.00→0.985→1.00` 回弹；计数器 12→24→37 改为**在闪白帧整字替换**（不要淡入），让"数字被拍下来"有物理感。

### 4【15.27–18.83】"谱行吸附"这一段的音效是**半哑的**，而且飞行中的行是半透明的

- **【秒】** 画面 12 行落栈 ≈15.27 → 18.83（步长 0.30s = 9 帧，正好 2 个 16 分 ✔）；之后 18.83 → 20.65 空 1.8s
- **【现象】** ① 对 mp4 音轨做 HF 瞬态检测，12 个落点里只有 **6 个有清楚的 tick**（15.29 / 15.59 / 16.79 / 17.39 / 17.99 / 18.59，误差 ≤0.02s）；**第 3–5 行（15.87 / 16.17 / 16.47）完全没有可辨识的落点音**（HF onset 只有 1.9–4.8，与音乐里 16 分 hi-hat 的 2–5 完全同量级——被埋了）；第 7 / 9 / 11 行偏 **0.07–0.12s**。这条本该是全片最爽的"12 连击"，结果是"6 响 + 3 哑 + 3 飘"。
  ② 装填动作本身是 **0.82s 的 ease_out_cubic 浮入**（≈25 帧），比行间距（0.30s）长近 3 倍，等于永远有 3 行在半空；而 `opacity` 直接绑在进度 `p` 上——**飞行中的行是半透明的**，能从它身上看见后面的谱行（`snap_17.8_19.1` 拼图里 f508–f514 最明显）。纸透纸 = 穿帮。
- **【修法】** ① 12 个落点音**每行必给**，且电平至少比 hi-hat 高 **6 dB**（现在是被 hi-hat 淹没的）；tick 的音高用 `900 × 2^(i/12)` 的五声音阶（不要 12 平均律，会和音乐打架），时间严格 = 落点帧。② 飞行改 **0.34s（10 帧）**、`ease_out_quint`，落点前 0.06s `scale 1.04` 预压、落点后 0.10s 回 1.00（`cubic-bezier(0.34,1.56,0.64,1)`）；0.30s 间隔 / 0.34s 飞行 ≈ 只重叠 1 行，才有"接力吸附"的密度。③ 飞行中 `opacity` 必须 **1.0**，改用**阴影**表达高度（越高越虚、偏移越大），不要用透明度。④ 18.83–20.65 的 1.8s 空档必须填：把去重提前到 **19.20**（第 10 小节线，也是音轨里最响的 onset 之一 19.18），第 1 行重复的琥珀标记在 19.20 起闪、19.60 死掉。

### 5【26.40–35.90】"核验"9.5 秒是一张静止截图，而全段唯一的动作被一个**单帧删除**收尾

- **【秒】** 26.4–35.9（66% 的帧活跃 <1%，中位 **0.14%**）；选中态 27.57 → 27.70 进（0.13s，落在 16 分格 27.60 ±0.03 ✔）；**拖拽导致的高亮消失打在 30.37 一帧**（该帧 1.44% → 下一帧 0.00%）
- **【现象】** ① 镜头完全不动（26.4–33.2 整段是定机位），只有 12–19px 的小字和鼠标在动，视觉上是"给了一张 UI 截图让人读"。② 这段唯一有动势的是 **29.63–29.97 的行换位拖拽**（0.34s，峰值 2.6%/帧，节奏是对的），但**换位一落地，琥珀选中框在 30.37 这一帧直接归零**（该帧 1.44% → 下一帧 0.00%，前后帧都是 0.00%），浮动条也在这一秒前后收掉——观众刚看到"换好了"，还没来得及确认"保留哪一行"，画面就把证据擦了。这是"信息节奏"真正断掉的地方：**动作有起手、没有落点。**
- **【修法】** ① 26.50–35.90 做**单点透视慢推**：`scale 1.000→1.065`、`cx/cy` 锁在列表上 1/3 处、`ease_in_out_sine`（整段一条曲线，不要分段）；33.20 之后再叠一次 1.065→1.22 的加速推（`ease_in_cubic`），把"确认"变成"走进去"。② 30.37 不许硬删：换位落地后选中态**转为绿色"已保留"chip**（0.2s 弹入 + 0.1s 回弹，`cubic-bezier(0.34,1.56,0.64,1)`），停留到 32.60；浮动条先**收成 1 条 6px 高光线**（0.18s）再淡出（0.2s），不要整块消失。③ 落位要有"顿"：末 3 帧 `scale 1.01→1.00`，并补一声木鱼/纸拍（现在 29.35 只有起手的 whoosh，落地无声）。④ 元信息 12px / chip 13px → **≥16px**（1080p 安全线），540p 投放时它只有 6px，等于没有。

### 6【38.43–40.05 / 42.35–43.60】纸张段的两处"物理不可信"：翻页是"跳"出来的，微距退场是两层纸叠着化

- **【秒】** 翻页 38.43–39.90（可见运动 39.10–39.90）；微距退场 42.35–43.60
- **【现象】** ① 翻页的 tween 从 38.75 起，但**实测 38.43–39.07 这一段帧间变化只有 0.0–0.2%**（`ease_in_out` 的起手区几乎不动），真正的翻页是 **39.10–39.90（0.8s）**；更糟的是 **39.10 这一帧画面变化 10.94%**，而前后帧只有 2–7%——第二页是**一帧之间跳出来的**，不是翻出来的。同时音效 `paper_flip` 打在 **38.73**，于是"听得见的翻页"比"看得见的翻页"早 **0.37s**；而全片最响的一击（onset 通量 26.9，**38.38**）画面上什么都没有。
  ② 42.35–43.60 是 **2.15× 的微距页**与 **0.50× 的纸堆**同时存在做交叉淡化：42.6–42.8 的连续帧里能看到**两层不同比例的同一张谱面叠着**（大白块 + 重影字），540p 下糊成一团白光——明确的穿帮。
- **【修法】** ① 翻页压到 **0.42s（13 帧）**：`flip` 0→1 用 `cubic-bezier(0.45,0,0.25,1)`，页角沿 `f` 的导数给 2–4px 的运动模糊，末 0.08s 加 `rotate −2°` 过冲再回弹；**起手帧对齐 38.38**（全片最响的一击），音效 `paper_flip` 同步到 38.38，落地帧补一声"纸拍桌面"（现在翻完没有落地声）。② 微距退场**禁止交叉淡化**：改成同一张纸的连续运动——42.35–43.10 内 `scale 2.15→0.50`、`ry −8°→−24°`、`opacity` 恒为 1，`ease_in_out_quint`（`cubic-bezier(0.83,0,0.17,1)`）；纸堆层在 **42.95 之后**才允许 `opacity 0→1`（0.25s），中间绝不允许两页并存。③ 微距本身也要真的"微"：现在 42.7 只是"一张更大的整页"（页边还在画内、留白占了一半），把 `scale` 推到 **3.2×** 并锁定到某一个小节的品位数字上，纸纹/墨点才有地方出现。

### 7【45.60–59.60】结尾 14 秒：89% 的帧静止、推轨 0.13px/帧、光带在 47.30 一帧蒸发、一声 chime 打在空画面上

- **【秒】** 45.60–59.60（S6 内 **89.1% 的帧活跃 <1%**，中位 **0.00%**）；47.30–52.50（5.2s）与 52.87–59.20（**6.3s**）两段近乎完全静止
- **【现象】** ① 结尾的"慢推"是 8.2s 推 **3%** ≈ **0.13px/帧**——低于人眼在 1080p 的运动阈值，实际效果是**亚像素爬行**（还能看到双线性重采样的抖动），不是推镜。
  ② **光带在 47.30 被一帧蒸发**：该帧下半个画幅变化 **12.3%**、上半画幅 **19.9%**，而前后帧只有 0.1–0.2%——"一线光"不是淡出、不是收束，是**断电**。而它是全片唯一的运动母题（52.5 的 Logo 里又长出一条新的线）。
  ③ 纸页退场的收尾也是硬切：46.83/46.87/46.90 三帧变化 37/33/**25%**，46.93 直接 0.22%——最后一帧的纸是"啪一下没了"，不是淡尽。
  ④ 47.30–48.00 空 0.7s → 48.00–48.43 首行淡入（0.43s，**没有任何音效支撑**）→ 48.43–49.43 空 1.0s → 49.43–49.90 次行 wipe（音轨的 chime 在 49.18，**早 0.25s**）→ 49.90–52.50 空 **2.6s**。这段 5.2 秒里，画面只有两次文字淡入，中间夹着三段空。
  ⑤ **50.68 有一声清楚的 chime，画面上什么都没有**（全片唯一"有声无画"的地方）。
  ⑥ 52.50–52.87 的"Logo 绘制"只有 **0.37s**，而且是和文案淡出**交叉淡化**在一起（Logo 区活动 4→12% 的同时文案区也在动），读起来是"字的残影里冒出四个括号"；之后 53.43 产品名、55.47 slogan 的入场，**每帧只改变画幅 0.4–0.8% 的像素**（对比 S1 的健康值是 7–35%）——肉眼几乎抓不到，等于没发生。

## 3 个最好看的运动瞬间

1. **【14.00–15.00】青绿光带的展开与收缩**：光带在旧画面（白 UI）上从 1 条 2px 线在 0.36s 内涨满全屏（`ease_in`，越涨越快），14.40 切点瞬间变成新场景的地平线光源，再用 0.6s 收成一条线。**一次转场同时完成了"遮罩 + 光源 + 世界观建立"**，14.38 的 impact 与 14.40 的切点只差 1 帧。这是全片唯一"光即是转场"的设计，也是唯一让我觉得"这是有人拍过产品片"的地方。
2. **【22.05–23.20】AI 扫光 + 逐行打勾**：一条 2px 青绿扫描线带着 160px 宽的辉光从上往下梳过 12 行谱面，扫过的行右侧弹出 3px 发丝线 + 小勾（22.2 起每行 +0.05s），音轨的 whoosh/chime 在 22.05–22.20 咬住起手。**信息、情绪、音效三件事在同一秒解决**，产品感最强。唯一遗憾：勾在光到达之前就出现了（见问题 4 的同类因果倒置）。
3. **【45.55–46.95】纸页旋转退场 → 一线光起**：impact 45.54 起、45.62 峰（−8.6 dB，全曲最响的段落），纸页在 1.35s 内 `ry −8°→−20°`、`scale 1.45→0.49`、阴影同步变虚、位置下沉 40px，退到"只剩一条线"。**这是全片唯一有真实空间感的物体运动**（有旋转、有位移、有阴影耦合），也是情绪转折最干净的一刀——可惜这条线 0.8 秒后就被 47.30 那一帧删掉了（见问题 7）。

## 如果只改 3 处，让「节奏感」达到获奖级

**① 用一条"呼吸推轨 + 16 分微事件"填平 5 段死区（8.0–13.3 / 18.6–20.2 / 27.0–33.0 / 34.8–35.7 / 47.3–59.2）**
这 5 段合计 ≈ **23 秒**，其中 55.4% 的帧几乎不动——这是"节奏感"和获奖级之间唯一真正的鸿沟，不是缓动曲线能救的。做法统一：全片铺一条 `scale 1.00→1.06`、周期 2.4s（=1 小节）的呼吸推轨，`ease_in_out_sine` 永不停止；每个 16 分格给一个 **1–2px 的位移/明暗微事件**（哪怕是噪点位移、光斑呼吸）；每个小节线给一次 3–5px 的"顿"。**先让画面永远在动，再谈动得好不好。**

**② 三次硬切改成"2 帧闪白 + 切点即实体 + 0.28s 入位"**
7.2/26.4/36.0 现在是"5 帧白卡 → 切到空 → 0.5–0.8s 淡入"，把最贵的三次切点浪费了。改完后切点会从"软"变"重"，而且不需要动任何构图——纯时间重排：闪白 2 帧、切点前 1 帧把目标态算完、入场 0.28s；36.00 那记 −13.8 dB 的 impact 已经在位了，只要让纸**跟着声音一起落地**（而不是 4 帧后才弹进来）。**成本最低、收益最高的一次手术。**

**③ 让"一线光"活到最后，把结尾 13.6 秒变成"线索收束"**
47.30 不许断电；让它从 47.0 一直亮到 52.55，然后上移 240px + 缩短成 Logo 横杠，四角括号同时画出。结尾就从"字在淡入的静止画面"变成"全片唯一的母题完成闭合"——这是 6 秒静止和 6 秒"有意义的静止"的全部区别。顺带把结尾推轨从 3%/8.2s（0.13px/帧，等于没有）提到 10%（0.55px/帧），次行文案的 wipe 前移到 chime 的 49.18，50.68 那声"有声无画"的 chime 要么删、要么给它动作。

## 附录 C · 运动语言清单（73 处过渡）

`ease_out_cubic` 38 处 / `ease_in_out_cubic` 26 处 / `ease_in_cubic` 9 处；`ease_out_quint`（已实现）、`ease_out_expo`、`ease_out_back` **0 处使用**。
即：**这套片子只有三种运动性格**——"软着陆""缓起缓停""加速"。缺的是"砸下来"（back/overshoot）、"刹车不住"（expo out）、"弹簧"（spring settle）。建议按动作类型分配：吸附/落纸 → `ease_out_quint` + back(1.2) 过冲；镜头推轨 → `ease_in_out_sine`（永不使用 cubic，cubic 的起停太"设计软件"）；光带/扫描 → 线性 + 两端 0.1s 软化（物理光就是匀速）；文字 → 0.35s `cubic-bezier(0.16,1,0.3,1)`。
