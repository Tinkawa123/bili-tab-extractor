# 「视频扒谱工具」60 秒宣传片 · 交付说明

> 一支**完全由代码生成**的产品宣传片：画面、动效、排版、配乐、音效全部由 Python 程序逐帧渲染，
> 没有用任何 AI 视频模型、模板或素材站，也没有用剪辑软件。

## 三、技术实现

整个片子是一个**确定性函数** `film.frame(t) -> 图像`：

- **渲染**：Python + numpy + OpenCV + Pillow，1×（非 AI 生成）。逐帧可并行、可重跑、改一个时间点只影响该时间点。
- **字体**：正文/标题用 Noto Serif SC（思源宋体），功能字用 HarmonyOS Sans SC，数据/时间码用 Consolas；文字按 3× 超采样渲染后缩小，边缘干净。
- **合成**：预乘 alpha 合成、仿射/透视变换、各向异性运动模糊、形态学背景压平（把视频里的谱面行「洗」成白纸黑墨）。
- **影调**：bloom + halation 单次低频光晕、暗角、胶片颗粒、暖冷分离调色、黑位抬升（避免纯黑死块）。
- **配乐/音效**：`audio.py` 用加法合成/噪声合成生成 —— 尼龙吉他琶音、Rhodes、Pad、贝斯、Kick/Rim/Hat/Clap；
  音效含**相机快门**（截图）、UI 点击、纸翻页、上升音、Impact、AI 提示音等，全部按时间轴卡在 100BPM 的 16 分音符与小节线上（实测动作与音频瞬态误差 ≤ 35ms）。
- **生成流程**：`render.py video` 用多进程分段渲染 JPEG 帧 → ffmpeg 编码并混入音轨。

## 四、素材合规（重要）

- 视频画面与谱行**只用搬运向/无付费谱二创的素材**：`BV19f421Q76h`（Black Sabbath – Paranoid 吉他演奏，画面 + 该视频提取的 39 行真实谱行）。
- **没有使用**「阿怪弹吉他」等「谱子在简介付费获取」的 UP 主素材，避免让观众误以为在引导绕过付费。
- 产品界面、Logo、版式均为本片原创绘制（界面按真实产品功能重绘，非截图，避免泄露 API Key 等敏感信息）。

## 六、如何重新渲染 / 二次修改

```bash
cd promo
python audio.py                                        # 重新生成配乐音效（约 1 分钟）
python render.py stills 6.6 18.0 44.4 --scale 1.0      # 只渲染几个时间点的静帧（调试用）
python render.py video --fps 30 --scale 1.0 --workers 4 --tag final \
       --out out/视频扒谱工具_宣传片_1080p.mp4 --crf 16 --preset slow
```

- 想改文案/时间点：编辑 `film/design.py` 的 `T` 时间表和 `film/film.py` 里各 `sceneN()`；
- 想改配色/字体：`film/design.py`；
- 想改 A4 页版式：`film/pages.py`；
- 想换素材：替换 `film/assets/video/` 下的帧图（用 ffmpeg 从新视频抽帧），并把 `pages.ROWS_DIRS` 指向新的谱行目录。

## 七、已知局限

1. 只有 16:9 母版；9:16 竖版需要逐镜头重排（文字目前靠左，直接裁切会丢字）。
2. 片尾 CTA 用文字给出 GitHub/搜索路径，没有二维码（如需二维码可后续加一张图）。
3. 程序化配乐是「刻意克制」的 lo-fi 电子 + 尼龙吉他，不是商业曲库级混音；如要发行级音乐建议替换成授权曲目，画面时间轴已按 100BPM 卡好，换曲需重新对齐。
4. `out/frames_*` 是渲染中间产物，体积较大，确认成片后可删。
