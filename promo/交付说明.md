> 没有用任何 AI 视频模型、模板或素材站，也没有用剪辑软件。

## 三、技术实现

整个片子是一个**确定性函数** `film.frame(t) -> 图像`：

- **渲染**：Python + numpy + OpenCV + Pillow，逐帧生成（非 AI 生成）。可并行、可重跑、改一个时间点只影响该时间点。
- **字体**：标题用 Noto Serif SC（思源宋体），功能字用 HarmonyOS Sans SC，数据/时间码用 Consolas；文字按 3× 超采样渲染后缩小，边缘干净。
- **合成**：预乘 alpha 合成、仿射/透视变换、各向异性运动模糊、形态学背景压平（把视频里的谱面行「洗」成白纸黑墨再印到纸上）。
- **影调**：单次低频 bloom + halation、暗角、胶片颗粒、暖冷分离调色、黑位抬升（避免纯黑死块）。
- **配乐/音效**：`audio.py` 用加法合成/噪声合成生成 —— 尼龙吉他琶音、Rhodes、Pad、贝斯、Kick/Rim/Hat/Clap；
  音效含**相机快门**（截图）、UI 点击、纸翻页、上升音、Impact、AI 提示音等，全部卡在 100BPM 的 16 分音符与小节线上（实测动作与音频瞬态误差 ≤ 35ms）。
- **生成流程**：`render.py video` 多进程分段渲染 JPEG 帧 → ffmpeg 编码并混入音轨 → 二次转码为 yuv420p(tv)/bt709 发布版。

## 四、素材合规（重要）

- 视频画面与谱行**只用搬运向 / 无付费谱二创的素材**：`BV19f421Q76h`（Black Sabbath – Paranoid 吉他演奏，画面 + 该视频提取的 39 行真实谱行）。
- **没有使用**「阿怪弹吉他」等「谱子在简介付费获取」的 UP 主素材，避免让观众误以为在引导绕过付费。
- 产品界面、Logo、版式均为本片原创绘制（界面按真实产品功能重绘，非截图，也避免泄露 API Key 等敏感信息）。

## 五、评分子智能体与迭代（用户要求）

请了 4 位不同视角的评分子智能体（艺术指导 / 动效剪辑 / 营销创意 / 苛刻观众），做了两轮打分并逐条修：

| 轮次 | 评委 | 分数 | 主要结论 |
|---|---|---|---|
| 第 1 轮 | 艺术指导 Judge A | 60/100 | 白闪过曝、纸带色偏、幽灵矩形、片尾层级倒置、字幕 wipe 切碎汉字 |
| 第 1 轮 | 营销创意 Judge C | 56/100 | 13 秒没人话、痛点信息太小、片尾 0 转化、找回漏行没演 |
| 第 1 轮 | 苛刻观众 Judge D | 52/100 | 结尾 11 秒静置、无获取入口、错别字「手截」、小字全灭 |
| 第 1 轮 | 动效剪辑 Judge B | 52/100 | 55% 帧几乎不动、三次转场同一模板、纸透纸、光带一帧蒸发 |
| **第 2 轮** | 艺术指导 Judge A（复审） | **71/100（+11）** | 7/11 项修到位；又抓出 3 个 P0（S5 主镜头被误写阴影压暗、窗口阴影硬边、S6 光带硬矩形/双横线） |
| **第 2 轮** | 苛刻观众 Judge D（复审） | **68/100（+16）** | 从「不转发」变「会转但先吐槽」；指出浮条无淡出、片尾 2.9s 静置、成品页出现相邻重复行 |

**已按意见落地的修改**（按两轮反馈逐条）：

1. 字幕改为「淡入 + 上浮」，彻底解决 wipe 把汉字切半的问题；HUD 数字也不再硬切。
2. 白闪改为局部取景框闪光；三次切点闪白缩短到 2–4 帧；三次转场各有光签名（斜向扫光 / 暖光 / 冷青）。
3. 谱面纸带校色成暖纸（从薄荷灰 (200,226,225) 到 (180,170,155)），顶部加渐变阴影、青绿 glow 减弱。
4. A4 页：每行谱先做形态学背景估计再除，压平视频高光与高亮区块；新增正视满页主镜头；换用不相邻的 5 行；修掉误写的整页阴影（纸面亮度 114 → 254）。
5. `engine.shadow()` 补 3σ 画布，一次修掉窗口/S5/S6 共 5 处硬边黑带。
6. 幽灵矩形全部羽化；S3 全宽扫描光改为只覆盖源视频卡。
7. 黑位抬升 + 暗角减弱，纯黑像素占比 25% → 0%。
8. 片尾重做：Logo 逐笔、产品名 84px、真实 CTA（WINDOWS·免安装·免费 / B站·GitHub 搜索 / GitHub 地址）、慢推镜、主角线一直活到 Logo 横杠；删掉 2:1 对比度的页脚。
9. S1 核弹信息升到 96px，左上 60px 计数器；截图卡片改为真实谱面打印卡。
10. S3 补四句人话、章节标签移出画面主体、行卡切边修正；S4 演出「找回漏行」并加淡出。
11. 数字口径统一：48 行 − 12 重复 = 36 行 / 8 页；导航 30 块。
12. 错别字修正：「一键扒谱 · 专治手截」→「一键扒谱 · 不用手截」。

## 六、如何重新渲染 / 二次修改

```bash
cd promo
python audio.py                                        # 重新生成配乐音效（约 1 分钟）
python render.py stills 6.6 18.0 44.4 --scale 1.0      # 只渲染几个时间点的静帧（调试用）
python render.py video --fps 30 --scale 1.0 --workers 4 --tag final \
       --out out/视频扒谱工具_60s_1080p.mp4 --crf 16 --preset medium
```

- 改文案/时间点：`film/design.py` 的 `T` 时间表 + `film/film.py` 各 `sceneN()`；
- 改配色/字体：`film/design.py`；
- 改 A4 页版式：`film/pages.py`；
- 换素材：替换 `film/assets/video/` 下的帧图（用 ffmpeg 从新视频抽帧），并把 `pages.ROWS_DIRS` 指向新的谱行目录。

## 七、已知局限（还想继续打磨的话）

1. 只有 16:9 母版；9:16 竖版需要逐镜头重排（文字目前靠左，直接裁切会丢字），这是目前离「全平台分发」最远的一步。
2. 片尾 CTA 用文字给出 GitHub/搜索路径，**没有二维码**（加二维码需要额外的生成库/图片）。
3. 程序化配乐是刻意克制的 lo-fi 电子 + 尼龙吉他，不是商业曲库级混音；如要发行级音乐建议替换成授权曲目（画面按 100BPM 卡好，换曲需重新对齐）。
4. `out/frames_final/`（约 0.4 GB）是渲染中间产物，确认成片后可删。
5. `_dev/` 是调试与评委取证脚本的归档，不影响成片。
